# LEGO Analysis for Course

Hari ke-74 kursus *100 Days of Code* Udemy: mengagregat dan menggabungkan data dalam Pandas semasa menganalisis set data LEGO. Wiki ini menerangkan apa yang diajar oleh setiap langkah kuliah. Setiap langkah mempunyai tangkapan skrin yang dijana daripada kod.

| Halaman | Apa yang anda perolehi |
| --- | --- |
| [Bermula](Getting-Started-ms) | Sebuah `.venv`, pemasangan dan cara menjalankan serta menguji projek |
| [Langkah 1: Meneroka warna bata](Step-1-Colours-ms) | Berapa banyak warna yang dihasilkan LEGO, dan berapa yang lut sinar? |
| [Langkah 2: Set tertua dan terbesar](Step-2-Sets-ms) | Bilakah set pertama dikeluarkan, berapa banyak set ketika itu, dan set manakah yang mempunyai bahagian paling banyak? |
| [Langkah 3: Set yang dikeluarkan setiap tahun](Step-3-Sets-per-Year-ms) | Bagaimanakah bilangan set yang dikeluarkan berubah dari semasa ke semasa? |
| [Langkah 4: Tema setiap tahun dengan .agg()](Step-4-Themes-per-Year-ms) | Berapa banyak tema berbeza yang dijual LEGO setiap tahun? |
| [Langkah 5: Dua paksi dalam satu carta](Step-5-Two-Axes-ms) | Bagaimanakah set dan tema boleh berkongsi satu carta apabila skalanya berbeza? |
| [Langkah 6: Purata bahagian setiap set](Step-6-Parts-per-Set-ms) | Adakah set LEGO bertambah besar dan kompleks? |
| [Langkah 7: Tema, kunci utama dan kunci asing](Step-7-Themes-and-Keys-ms) | Nama tema manakah yang dimiliki oleh id tema, dan bagaimanakah jadual dihubungkan? |
| [Langkah 8: Menggabungkan DataFrame pada satu kunci](Step-8-Merge-ms) | Bagaimanakah kita menggabungkan bilangan set setiap tema dengan nama tema? |
| [Langkah 9: Carta bar 10 tema teratas](Step-9-Bar-Chart-ms) | Tema manakah yang mempunyai set paling banyak? |
| [Ringkasan](Summary-ms) | Segala yang diajar oleh kuliah, dalam satu senarai |

Lima soalan tugasan: set terbesar, tahun pertama dan set-setnya, tema dengan set paling banyak, pertumbuhan set dan tema setiap tahun, dan sama ada set bertambah besar.
