# Apa yang diajar oleh kuliah

- Sel Markdown dengan HTML: tajuk dengan `#` dan imej dengan teg `<img>`.
- `.nunique()`, `.value_counts()` dan `.groupby().count()` untuk mengira.
- `.sort_values()` dan penapisan dengan satu syarat.
- Mengiris DataFrame seperti senarai, contohnya `df[:-2]` dan `df[:10]`.
- `.agg()` dengan kamus untuk menjalankan satu operasi bagi setiap lajur, dan `.rename()` untuk nama lajur.
- Carta garis dengan dua paksi berasingan (`.twinx()`), carta serakan dan carta bar dalam Matplotlib.
- Kunci utama dan kunci asing dalam pangkalan data hubungan, dan `pd.merge(..., on="id")` untuk menggabungkan jadual.

Jawapan: set terbesar mempunyai 9,987 bahagian, LEGO bermula pada 1949 dengan 5 set, Star Wars mempunyai set paling banyak (753), julat set dan tema meningkat dengan kukuh sejak pertengahan 1990-an, dan purata set meningkat daripada kira-kira 12 bahagian (1954) kepada kira-kira 222 (2017).
