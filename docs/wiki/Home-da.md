# LEGO Analysis for Course

Dag 74 af Udemys *100 Days of Code*: aggregér og flet data i Pandas, mens du analyserer et LEGO-datasæt. Denne wiki forklarer, hvad hvert trin i lektionen lærer dig. Hvert trin har et skærmbillede genereret fra koden.

| Side | Hvad du får ud af det |
| --- | --- |

| [Trin 1: Udforskning af klodsernes farver](Step-1-Colours-da) | Hvor mange farver laver LEGO, og hvor mange er gennemsigtige? |
| [Trin 2: De ældste og de største sæt](Step-2-Sets-da) | Hvornår udkom de første sæt, hvor mange var der, og hvilket sæt har flest dele? |
| [Trin 3: Udgivne sæt pr. år](Step-3-Sets-per-Year-da) | Hvordan ændrede antallet af udgivne sæt sig over tid? |
| [Trin 4: Temaer pr. år med .agg()](Step-4-Themes-per-Year-da) | Hvor mange forskellige temaer solgte LEGO hvert år? |
| [Trin 5: To akser i ét diagram](Step-5-Two-Axes-da) | Hvordan kan sæt og temaer dele ét diagram, når deres skalaer er forskellige? |
| [Trin 6: Gennemsnitligt antal dele pr. sæt](Step-6-Parts-per-Set-da) | Blev LEGO-sættene større og mere komplekse? |

| [Trin 9: Et søjlediagram over de 10 største temaer](Step-9-Bar-Chart-da) | Hvilke temaer har flest sæt? |
| [Opsummering](Summary-da) | Alt, hvad lektionen lærte, i én liste |

Opgavens fem spørgsmål: det største sæt, det første år og dets sæt, temaet med flest sæt, væksten i sæt og temaer pr. år, og om sættene blev større.
